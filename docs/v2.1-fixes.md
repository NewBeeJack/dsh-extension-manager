# V2.1 defect fixes

> Local build 0.3.2. Not published.

## Root causes

1. **Cross-scope check results**: the page had one global `activeTask` and rendered its `TaskPanel` regardless of the selected scope. Task completion wrote status/toasts into the current page's context.
2. **Inert group headers**: `RecordList` received `forceOpen={multipleFilters}`; whenever a search/source/status/range filter was active the render used `forceOpen || !collapsed.has(key)`, so toggling the stable group key changed state but could never close the group.
3. **Redundant row actions**: `RecordRow` rendered an update button, a per-row check `IconAction`, a detail arrow and a path-copy button, while the name itself was a second detail button.

## Changes

- `activeTasks` is keyed by `plugins`/`skills`; only the current scope is rendered. Task polling, attribution, toast suppression and stale-response guards use the owning slot and task id. The two slots retain independent result panels and both can remain available for later tab switches.
- `TaskPanel` detail visibility is controlled by the page; dismissed and expanded states live in per-scope `taskViews`, so closing one panel never clears the other's panel or the business check result.
- `forceOpen` is false for the real list; groups are keyed by their existing stable source-group key and toggled by a semantic button with `aria-expanded`/`aria-controls`.
- Main rows render only a static name plus one right-side icon button named “查看详情”. Update/check/copy controls are gone from rows; the details dialog retains check/update, and the top toolbar keeps batch check/update.
- Existing update engine, discovery, scope rules, cache and details data are untouched.

## Verification

- 119/119 tests, typecheck and build pass.
- Isolated browser: Plugins check → immediately Skills: no Skills panel/toast; return Plugins shows the completed panel. Reverse direction likewise.
- Both scopes completed: each shows its own task item count/message; closing and expanding states are independent.
- npm/source-unknown/search/source/status/range/sort group collapse verified; states survive Plugins↔Skills switching.
- Plugins 6/6 and Skills 12/12 rows expose exactly one `aria-label="查看详情"` button; clicking it opens the existing details.
- Top update-all still opens the existing plan (2 automatic updates, 1 confirmation skipped) and cancellation does not execute an update.
